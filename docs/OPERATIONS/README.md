## Common Tasks

### Daily Operations
1. Start here → [OPERATIONS_RUNBOOK.md](OPERATIONS_RUNBOOK.md)
2. See health checks section
3. Review metrics in [MONITORING_GUIDE.md](MONITORING_GUIDE.md)

### System Won't Start
1. Check [TROUBLESHOOTING_FOR_OPS.md](TROUBLESHOOTING_FOR_OPS.md) → "System Startup" section
2. Review logs
3. If blocked → [ESCALATION_PROCEDURES.md](ESCALATION_PROCEDURES.md)

### Something's Wrong
1. Check [TROUBLESHOOTING_FOR_OPS.md](TROUBLESHOOTING_FOR_OPS.md) for your symptom
2. Run the diagnostic steps
3. If unresolved → file incident per [INCIDENT_RESPONSE.md](INCIDENT_RESPONSE.md)
